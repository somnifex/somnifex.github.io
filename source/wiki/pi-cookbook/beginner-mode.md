> 🟢 新手起点 | 本章假设你**完全不懂编程**，只想让 Pi 帮你干活。所有步骤都可以照抄。

## 本章目标

- 不需要记任何命令，也能启动 Pi
- 知道怎么让 Pi 帮你读文件、改文件、写东西
- 知道 Pi 不会“自动害你”，但你也要学会审查它的操作

---

## 第一步：找到你的“启动按钮”

Pi 是一个命令行程序，但我们可以把它做成一个**双击就能打开的图标**。

### Windows 用户

1. 在桌面新建一个文本文件，重命名为 `pi.bat`（注意后缀是 `.bat`，不是 `.txt`）
2. 右键 → 编辑，写入：

```bat
@echo off
cd /d "C:\Users\howie\Desktop\MyProject"
pi
pause
```

3. 保存，双击 `pi.bat`，就会打开一个黑色窗口，里面就是 Pi

### macOS 用户

1. 打开“文本编辑”，新建文件，写入：

```bash
#!/bin/bash
cd ~/Desktop/MyProject
pi
read -p "按任意键关闭..."
```

2. 保存为 `pi.command`（后缀必须是 `.command`）
3. 在终端里执行一次：`chmod +x ~/Desktop/pi.command`
4. 以后双击 `pi.command` 就能打开 Pi

### Linux 用户

```bash
#!/bin/bash
cd ~/Desktop/MyProject
pi
read -p "按任意键关闭..."
```

保存为 `pi.sh`，执行 `chmod +x pi.sh`，以后在文件管理器里双击即可。

---

## 第二步：第一次对话

启动后，你会看到一个黑色窗口，顶部显示模型名称和快捷键。底部有一个 `>` 光标，那就是你输入的地方。

### 你可以输入的第一句话

```
帮我看看这个文件夹里有什么文件，告诉我每个文件是干什么的。
```

按 Enter，Pi 会开始读文件、分析、然后回复你。

### 再试一句

```
帮我写一个购物清单，保存为 shopping.txt
```

Pi 会创建一个 `shopping.txt` 文件，并写入内容。

### 再试一句

```
把 shopping.txt 里的内容读出来，然后改成英文版本，保存为 shopping-en.txt
```

Pi 会先读原文件，再写一个新文件。

---

## 第三步：审查 Pi 的操作

Pi 每次执行操作前，会在屏幕上显示一行类似这样的提示：

```
[read] shopping.txt
[write] shopping-en.txt
```

你的工作是：扫一眼它要干什么。读文件、读配置、写一个你看得懂的新文件——这些都是日常操作，扫一眼放过去就好。但 Pi 没有内置的“弹窗确认”，所以你需要自己保持注意力。如果它突然要 `rm`、`sudo`、覆盖某个你认不出的脚本，立刻按 `Esc` 中断这一轮，然后回过去看它到底想干什么。

---

## 第四步：结束对话

- 输入 `/quit` 或直接关闭窗口
- 下次打开时，可以输入 `/resume` 继续上次的对话

---

## 常见问题

| 问题 | 解决 |
|------|------|
| 窗口闪一下就关了 | 检查 `pi.bat` 里的路径是否正确 |
| 提示“找不到 bash” | Windows 用户需要安装 Git for Windows |
| 输入中文没反应 | 换个终端试试（推荐 Windows Terminal） |
| Pi 回复很慢 | 正常现象，它在调用大模型，等一下就好 |

---

## 你现在应该会什么

到这里你应该能：

- 找到或写一个一键启动 Pi 的脚本（按系统选 `.bat` / `.command` / `.sh`）
- 让 Pi 读、改、写一个本机文件
- 看懂 Pi 执行前的 `[read] / [write]` 提示，按 Esc 取消异常动作
- 用 `/quit` 退出，用 `/resume` 接回历史会话
